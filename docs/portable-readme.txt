DevShop 本地 JSON / JWT 工作台

Windows：完整解压后运行 devshop.exe。
macOS / Linux：完整解压后运行 devshop，目标系统需要图形桌面和相应动态库。
本包为未签名便携程序；macOS 包未签名或公证。

JSON 支持后台解析、树形浏览、应用内搜索、格式化、压缩与保存。
JWT 支持本地解码、编辑与签名验证；密钥默认不进入历史或保存文件。
历史记录和已保存内容位于当前用户目录，包含所处理的内容，请按自己的保留需要管理。

悬浮球：单击打开，拖动移动，右键读取剪贴板、查看历史或完全退出。
主窗口关闭后可保留悬浮球；应用内可以关闭悬浮球。

Windows 可选安装：在完整包目录运行 install.ps1。
安装添加开始菜单 Shop/DevShop 和 .json/.jwt 的“打开方式”，不更改默认应用。
后续从同一源码仓库成功打包，会自动更新已经安装的固定入口。
启动器固定路径读取 current.path；正在运行的实例保留当前版本，退出重开后使用新包。
