## DevShop 的实现选择

以下为本项目的设计，不声称是两个网站的内部实现：

- JSON 原文加紧凑节点索引，保留数字、顺序和重复字段。
- 后台解析、格式化、搜索和可见树行计算；树形与大文件原文按可见行绘制。
- 应用内搜索包含折叠节点，字段名和值可分别选择。
- 历史记录、文件保存、来源链、置顶悬浮球和单实例文件打开。
- JWT 密钥不进入历史与导出；签名状态与时间声明分开显示。

REA 仅进行了以上声明的浏览器动作。证据不覆盖网站后端实现、全部算法兼容性、账户功能或所有错误分支；页面事件顺序不等于因果关系，临时浏览器均由 REA 清理关闭。
